Third-party code and tools bundled with ffcx:

- ff7ecapi (shalzuth, MIT): catalog format, bundle XOR and master-data decryption method — ff7ecapi.txt
- vgmstream (ISC-style, see vgmstream.txt): CRI ACB/AWB/HCA decoding; its public key list provides the FF7EC CRI key
- FFmpeg (GPL build, https://ffmpeg.org/ — source: https://github.com/FFmpeg/FFmpeg): FLAC encoding, MKV muxing
- UnityPy (MIT), WannaCRI (MIT), NumPy, Pillow, cryptography, lz4, msgpack: see their packages' licenses
