# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository. Include what you found, how to reproduce it and
what an attacker could do with it. We aim to reply within 7 days.

In scope: the web app, the Azure Functions API (cloud saves, telemetry, update feed), the Static Web App
configuration, the installer (`irm | iex`) and the extractor.

Out of scope: the original game and its servers, and issues that need a compromised local machine.

## Supported versions

Only the latest release and the hosted site are supported.
